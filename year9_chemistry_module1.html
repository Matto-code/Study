🧱 Elements vs compounds

Element
A substance made of only one type of atom. Every atom has the same atomic number. e.g. oxygen (O), gold (Au), carbon (C).
Compound
Two or more different elements chemically bonded together in a fixed ratio, with new properties different from the elements it's made of. e.g. water (H₂O), carbon dioxide (CO₂).

The key contrast: an element can't be broken down into anything simpler by chemical means. A compound can be broken down into the simpler elements that formed it — and once broken down, those elements no longer share the compound's properties (e.g. water is a liquid that puts out fires, but it's made of hydrogen and oxygen — both gases, and hydrogen is flammable).

⚛️ Structure of the atom

All atoms are built from the same three subatomic particles, arranged the same way: a tiny, dense nucleus (protons + neutrons) at the centre, surrounded by electrons in shells.

What "relative mass" means: protons and neutrons are so tiny that measuring their actual mass in kilograms isn't practical. Instead, scientists compare every particle's mass relative to a proton — so a proton or neutron is given a relative mass of 1, and an electron (about 2000× lighter) is given a tiny fraction, 1/1840. It's a comparison scale, not an actual weight.
Atoms are electrically neutral: the number of protons always equals the number of electrons, so the positive and negative charges cancel out.

🔢 Atomic number & atomic mass

These two numbers are given for every element on the periodic table, usually above and below its symbol.

Atomic number (Z)
The number of protons in the nucleus. This is what defines the element — every atom of a given element has the same atomic number. It also tells you the number of electrons (since atoms are neutral).
Atomic mass / mass number (A)
The total number of protons + neutrons in the nucleus.

You can find the number of neutrons using:

Neutrons = Atomic mass (A) − Atomic number (Z)

Worked example: Sodium (Na)

Sodium has atomic number 11 and atomic mass 23.

  • Protons = 11 (the atomic number)
  • Electrons = 11 (same as protons)
  • Neutrons = 23 − 11 = 12
Reading the periodic table: for most periodic tables, the smaller number is the atomic number (protons) and the larger number is the atomic mass. If you're only given one number and asked for the other, check whether it's whole (likely atomic number) or has a decimal (likely atomic mass, since it's often an average across isotopes).

🎯 Electrons occupy discrete energy levels

Electrons don't orbit the nucleus randomly — they sit in specific, fixed energy levels (also called shells) at set distances from the nucleus. "Discrete" means there's no in-between: an electron is in one shell or another, never partway between two shells.

Sodium (11 electrons): 2 in shell 1, 8 in shell 2, 1 in shell 3

📏 Why the number of shells varies

Each shell can only hold a maximum number of electrons before the next shell has to start being used. Because of this, atoms with more electrons need more shells to fit them all in.

  • An atom with only 1–2 electrons (hydrogen, helium) only needs shell 1.
  • An atom with up to 10 electrons (like neon) fills shells 1 and 2.
  • Bigger atoms need shell 3, and beyond, to hold all their electrons.
Key rule: shells always fill from the innermost shell outward. You can't start putting electrons in shell 2 until shell 1 is completely full.

⚙️ The Bohr model: 2, 8, 8

For the first 18 elements (up to argon), the maximum number of electrons each shell can hold follows a simple rule:

ShellMaximum electrons
Shell 1 (innermost)2
Shell 28
Shell 38 (up to argon, element 18)

An electron configuration is just a shorthand list of how many electrons sit in each shell, written as numbers separated by commas — e.g. sodium is written 2, 8, 1.

✍️ How to work it out

  1. Find the atomic number — this tells you the total number of electrons.
  2. Fill shell 1 first, up to a maximum of 2.
  3. Fill shell 2 next, up to a maximum of 8.
  4. Put any remaining electrons in shell 3 (up to 8, for elements up to argon).

Exam tip: the number of shells used in an element's configuration matches its period (row) on the periodic table — e.g. sodium is in period 3 and uses 3 shells.
