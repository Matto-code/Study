Angles and parallel lines (7C)

A transversal is a line crossing two others. When it cuts two parallel lines (marked with matching arrows), matching angle pairs are either equal or add to 180°.
F — corresponding
Same position · equal
Z — alternate
Inside, opposite sides · equal
C/U — cointerior
Inside, same side · add to 180°
Checking if lines are parallel works backwards: if corresponding or alternate angles are equal, or cointerior angles add to 180°, the lines are parallel. If not, they aren't.
Naming angles: ∠ABF means the angle at B (the middle letter), between arms BA and BF. The middle letter is always the corner.
Careful: only use F, Z or C when the lines are marked parallel. Trace the letter shape with a finger before deciding "equal" or "add to 180°".

Multi-step problems (7D)

Find an angle you can work out, label it (x or y), then use it to reach a. Write a reason on every line.
  1. Mark the parallel lines and the angles you know.
  2. Look for an F, Z or C shape linking a known angle to a new one. Label it.
  3. Finish with a straight line (180°), revolution (360°) or triangle (180°).
The zig-zag trick: when a corner sits between two parallel lines (like a "<" pointing into the gap), draw a dashed line through the corner parallel to the others. The corner angle = the two outer angles added together (two Z's).
Algebra angles: use the rule to write an equation, then solve. Remember 2x means 2 × x, so divide at the end.
Reflex angles (bigger than 180°): use the revolution rule — 360 − the smaller angle.

Worked examples

Zig-zag: a corner B sits between two parallel lines. The angle at the top line is 37° and at the bottom line is 42°. Find ∠ABC. ▼
1
Draw a dashed parallel line through B, splitting the corner into x and y.
2
x = 37° (Z) and y = 42° (Z)
3
∠ABC = 37 + 42
✓ ∠ABC = 79°
(5a)° and 120° are cointerior angles. Find a. ▼
1
Cointerior add to 180°: 5a + 120 = 180 (C)
2
Subtract 120: 5a = 60
3
Divide by 5: a = 12
✓ a = 12

Angle sum and exterior angles (7G)

The three inside angles of any triangle add to 180°. An exterior angle is made by extending one side — it sits on a straight line with the inside angle next to it.

Classifying triangles (two names each)

By sidesMeaningBy anglesMeaning
Equilateral3 equal sides (all angles 60°)AcuteAll angles under 90°
Isosceles2 equal sides (2 equal base angles)RightOne angle exactly 90°
ScaleneNo equal sidesObtuseOne angle over 90°
Matching dash marks on sides mean those sides are equal. In an isosceles triangle, the two angles at the ends of the odd side (opposite the equal sides) are equal.
Two ways to find an exterior angle: find the inside angle next to it and subtract from 180°, or use the shortcut — exterior angle = the two opposite inside angles added together.
Bigger shapes: split from one corner into triangles. 4 sides → 2 triangles (360°); 5 sides → 3 triangles (540°); 6 sides → 4 triangles (720°).
Careful: the little square in a corner means 90° — don't forget to include it.

Symmetry (7H)

A line of symmetry folds a shape into two matching halves. The order of rotational symmetry is how many times a shape looks the same in one full turn (order 1 = no rotational symmetry).
ShapeLines of symmetryOrder of rotation
Square44
Rectangle22
Rhombus22
Parallelogram02
Kite11 (none)
Isosceles trapezium11 (none)
Equilateral triangle33
Isosceles triangle11 (none)
Scalene triangle01 (none)
Regular pentagon / hexagon / octagon5 / 6 / 85 / 6 / 8
For any regular shape: lines of symmetry = order of rotation = number of sides.
Careful: a parallelogram has no lines of symmetry — folding along a diagonal doesn't match.

Reflection, rotation and translation (7I)

The image of point A is called A′ (said "A dash").

TransformationWhat happensShortcut
Reflect in the y-axisFlip left–right(x, y) → (−x, y)
Reflect in the x-axisFlip up–down(x, y) → (x, −y)
Rotate 180° about OHalf turn(x, y) → (−x, −y)
Rotate 90° clockwise about OQuarter turn right(x, y) → (y, −x)
Rotate 90° anticlockwise about OQuarter turn left(x, y) → (−y, x)
TranslationSlide, no turningLeft/right changes x, up/down changes y
270° clockwise = 90° anticlockwise. 360° puts a point back where it started.
Mirror lines that aren't an axis: count squares from the point to the mirror, then the same number past it. Diagonal mirrors: each corner moves straight across the mirror at right angles, the same distance on the other side.
Rotations on paper: each point stays on its own dashed circle and moves a quarter (90°) or half (180°) of the way round. Tracing paper helps a lot. Clockwise = the way clock hands move.

Spatial patterns (2I)

A spatial pattern is a row of growing shapes (usually matchsticks). Every pattern has a starting design and a repeating design that gets added each time.
  1. Draw the next two shapes.
  2. Make a table of values: number of shapes vs number of sticks.
  3. Find the rule: sticks = (the jump each time) × shapes + (whatever is left over).
  4. Predict: substitute the number of shapes asked for (often 20 or 30).
Shared edges matter. If shapes share a side, the jump is smaller than the full shape. If they only touch at a corner, nothing is shared: sticks = sides × shapes.
Careful: "+5" describes the pattern but isn't a rule. A rule works for any shape number, e.g. m = 5h + 1. Always check it against the first two shapes.

Worked example

Hexagons sharing a side use 6, 11, 16, 21 sticks. Find the rule, the sticks for 20 hexagons, and how many hexagons 76 sticks makes. ▼
1
Goes up by 5 each time → start with 5 × h
2
For 1 hexagon: 5 × 1 = 5, but we need 6 → add 1. Rule: m = 5h + 1
3
20 hexagons: 5 × 20 + 1 = 101
4
Backwards: 5h + 1 = 76 → 5h = 75 → h = 15
✓ m = 5h + 1 · 101 sticks · 15 hexagons

Tables and rules (2J)

A rule like output = (3 × input) + 1 works like a machine: put a number in, follow the steps, get a number out. Replacing the input with a number is called substitution. Do the brackets first.

Finding a rule from a table

  1. Check the inputs go up by 1. How much does the output go up each time? That's what you multiply by.
  2. Multiply the first input by it and compare with the first output. The difference is what you add or subtract.
  3. Test the rule on another column.
Check simple rules first: 3 → 12, 4 → 13 is just + 9; 1 → 7, 2 → 14 is just × 7.
Inputs jump by 2? e.g. 2, 4, 6, 8 → 11, 17, 23, 29. The output rises 6 for every 2, which is 3 per 1. So 3 × input; 3 × 2 = 6 and 11 − 6 = 5 → output = (3 × input) + 5.
Outputs go down? e.g. 20, 18, 16 for inputs 1, 2, 3 → output = 22 − (2 × input).
Working backwards: undo the steps in reverse. If (3 × input) + 5 = 35: take 5 off (30), then divide by 3 (10).

The Cartesian plane (2K)

A point is written (x, y): x first (across), y second (up or down). "Along the corridor, then up the stairs." The centre (0, 0) is the origin, O.
QuadrantWhereSigns
1stTop right(+, +)
2ndTop left(−, +)
3rdBottom left(−, −)
4thBottom right(+, −)
Quadrants are numbered anticlockwise from top right. A point with a 0 in it, like (0, 4), sits on an axis and isn't in any quadrant.
Most common mistake: plotting (y, x) instead of (x, y). Also count from the origin, not from 1.

Graphing rules (6G)

  1. Fill in the table of values using the rule.
  2. Turn each column into a point (input, output).
  3. Plot them. If they line up, the rule makes a straight line.
Rules that only add, subtract or multiply by a number (like output = input + 3) give straight lines. Rules like output = input × input give a curve.
Missing values on a straight line: the outputs go up by the same amount each step. In 3, 5, A, 9, 11 the jump is 2, so A = 7.
Reading a rule off a graph: read each point into a table, then find the rule like in Patterns & rules. (0, 2), (1, 3), (2, 4) → output = input + 2.

Worked example

Graph output = (2 × input) + 1 for inputs 0 to 3. Is it a straight line? ▼
1
Outputs: 1, 3, 5, 7
2
Points: (0, 1), (1, 3), (2, 5), (3, 7)
3
The outputs go up by 2 every time, so the points line up.
✓ Yes — a straight line
